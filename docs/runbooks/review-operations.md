# Review operations

Alert: `review.backlog` (items past the review target, `REVIEW_SLA_HOURS`).

- Work the queue oldest first (Submissions → Review queue). Take the item so colleagues see it is assigned; release it if you stop.
- Read the receipt image and the rule results. Correct facts (number, date, total) when the photo is readable; qualification uses the corrected identity key.
- Decisions: qualify (awards an entry; becomes a duplicate automatically if the receipt is already credited), not qualified (choose the reason the participant will read), duplicate, ask for a new photo.
- Ownership disputes (same receipt from two phones): the candidate row links both; resolve it explicitly and decide each submission; only one can be credited.
- Identity conflicts (same key, different total): compare both images; usually a misread total; correct and qualify or mark duplicate.
- Escalate with a note when unsure; escalated items stay in the queue for a senior reviewer.
- Before a draw freeze, the barrier lists unresolved submissions in that period; clear them or record an override reason.
- A credited entry that turns out to be wrong is disqualified from Entries (reason; an independent approver if the entry is already in a draw). Reinstatement is possible.
