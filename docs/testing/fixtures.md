# Fixture set

Generated by `npm run fixtures` (`tools/gen-fixtures.ts`) into `fixtures/receipts/` with a `manifest.json` that labels each image with the expected document kind, disposition, reason and fields. Everything is fictional: retailers Mopani Mart, Baobab Stores, Jacaranda Foods and others; product Sweetvale Brown Sugar; towns are real place names only as strings. The pipeline never reads the manifest.

| Group | Fixtures | Exercises |
|---|---|---|
| Valid | valid-two-pack-A/B/C, valid-two-pack-A-photo, valid-three-pack-A, valid-multi-line-B | three receipt layouts, photographed variant, larger purchase still one award, sugar among other items |
| Not qualified | one-pack-A, two-kg-text-not-qty-C, wrong-sku-A, alt-pack-1kg-x4-B, void-line-A, date-before-window-A, date-after-window-A | quantity rules, "2KG" as a pack size not a quantity, wrong product, mixed packs off by default, void lines, purchase window |
| Review | non-participating-outlet-A, ambiguous-date-C, missing-receipt-no-B, cropped-top-A | outlet mismatch, day/month ambiguity that changes the outcome, incomplete identity, unreadable header |
| Re-upload | blurred-A, dark-A, random-photo, unrelated-paper | quality gate, non-receipts, instruction text inside an image |
| Duplicates | dup-photo-A, dup-cropped-A, dup-recompressed-A, dup-rotated-A, dup-no-total-B | same purchase in four re-photograph variants; total lost |
| Pool | pool-01 … pool-10 | distinct purchases for the seeded draw |
| UAT | uat-fresh-1-A, uat-fresh-2-B, uat-ambiguous-C | never seeded; reserved for the client script and the browser run |

Outlet CSV templates: `fixtures/outlets-import-template.csv` and `fixtures/outlets-import-invalid.csv` (used by the import dry-run demonstration).
