# Evidence

Machine-generated by the tools named below; regenerate before a release and commit the results. Screenshots are produced by the browser run.

| File | Tool | What it shows |
|---|---|---|
| `receipt-benchmark.{json,md}` | `npm run bench:receipts` | extractor agreement with the labelled fixtures, field accuracy, latency |
| `ocr-pipeline-results.json` | `npm run test:ocr` | every fixture's disposition through the full pipeline under real OCR |
| `load-benchmark.{json,md}` | `npm run bench:load` | throughput, latency percentiles, exactly-once, queue depth |
| `restore-rehearsal.json` | `npm run restore:rehearsal` | dump/restore integrity checks |
| `e2e-console.{json,md}`, `screenshots/` | `npm run test:e2e` | every role and page, the client UAT journey, desktop and mobile captures |

Private evidence (real receipts, client sign-offs) goes under `private/`, which is ignored by git.
